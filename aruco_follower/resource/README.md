# resource

This directory holds the `ament_index` resource marker for the `aruco_follower` package.

The file `aruco_follower` in this directory is an empty marker file consumed by the ROS 2 package index (`ament_index_python` / `ros2pkg`) so that tools like `ros2 pkg list` and `ros2 run` can discover the package once it's installed into a workspace.

It is a package-registration artifact, not application logic, and should not be edited or removed manually — `ament_python` creates and manages it automatically as part of the build.
